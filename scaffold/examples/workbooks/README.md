# Example Workbook Conventions

These CSV files are anonymised workbook-shaped examples. They are designed for
documentation, tests, fixture generation, and future validators. They are not
production workbooks.

- `group_meetings_rota_example.csv`: rota-driven meeting communications.
- `induction_recipients_example.csv`: induction recipient inputs.
- `induction_template_manifest_example.csv`: induction template selection and
  mode, asset, recipient-copy, and dry-run delivery policy metadata.
